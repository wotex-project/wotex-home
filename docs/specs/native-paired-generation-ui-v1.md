## Result and dependencies

The generation panel explicitly loads configuration and a matching retained
workspace for the selected paired controller, prepares roots/initial or repair
attempts, confirms with fresh signed scope, reconciles originals and separately
assesses a generated draft through ordinary manual authoring. It consumes the
implemented [workspace purpose](native-paired-generation-workspace-session-v1.md),
[original consumer](native-paired-generation-original-session-v1.md),
[v2 workspace](native-generation-workspace-v2.md), [v8 journal](native-pending-paired-authoring-v8.md)
and [selected authoring delivery](native-paired-authoring-ui-v1.md).
No Store, codec, dependency or sibling API addition is needed. Successful installed
signing/Keychain and real configured providers remain acceptance requirements.

## Configuration and frozen human decisions

**PGU-01.** An explicit configuration read obtains the actual selected factory,
current profile:manage and exact association/grants before any private projection
is read. Through that same five-second owner read identity, contract, options and
identity; principal/epoch and revisions agree and do not regress from acquisition.
Return checked options/contract/identity, selection snapshot/generation and paired
scope metadata. Retain no bearer, local capture or live session. Check delivery
expiry after the presentation hop; human editing may outlive the read lease.
Loading persisted workspace metadata itself performs no RPC. Before showing its
instruction/root, a separate explicit authenticated selected read matches exact
context/association/controller/creation/verifier. Another controller's workspace
is not a candidate for display or input export. No local fallback is allowed.

Policy/selected passages/examples and all budget fields start empty. Reuse the
closed generation codec: instruction0–4096 UTF-8 bytes, Cc forbidden except LF/tab;
canonical decimal attempts1–3, attempt_ms1–30000,total_ms1–120000 and attempt<=total.
Only explicit allowed sorted range/example rows and exact six policy limits may
enter the projection. Remote locality requires installed remote_export and a
separate unchecked export consent; LAN pairing is no model-export consent.
Configuration presence declares no provider authentication or confinement.

**PGU-02.** Preparing a root is pure over the checked context and explicit fields;
it creates a fresh complete canonical original with the reviewed Store revision.
Preparing an attempt obtains a new actual selected read session, requires matching
workspace custody, no cancellation intent, unchanged basis and actual current
policy/provider declaration, and reads exact root/latest history. Root must be
prepared. Initial attempt has index1/null predecessor/repair false. Repair requires
latest candidate with invalid mechanics, exact owned draft bytes matching result
and first revision, explicit feedback consent and remaining original attempt budget.
Show that draft/report privately. Preserve original root/limits/nonrenewing time;
no automatic attempt, changed predecessor, fallback or invented receipt is allowed.
Read current identity after all input work and require the same reviewed revision.

## Fresh confirmation and ordered publication

**PGU-03.** Confirmation obtains a fresh actual selected session and matches full
selection snapshot/generation, association, principal/epoch, unchanged grants,
exact reviewed revision, contract basis and complete options. Validate frozen
original and, for attempts, exact current retained workspace predecessor. Do not
edit IDs/revisions or reacquire after failure/possible send. Under that same original
five-second deadline/seal publish complete v2 root or exact one-attempt append,
then corresponding v8 pending original, then invoke the fixed original consumer.
Workspace publication uses full private-file CAS and actual session guards before
and after its bounded file owner; it does not renew authorization. Remember possible
workspace/pending publication and require reload on uncertainty. No workspace-only
send and no cross-file atomicity claim. Root preparation starts no model; attempt
handoff/running/settlement stay distinct. Keep unsettled attempt pending.

A paired result is a typed private delivery carrier with the actual sealed original
publication. The coordinator consumes only actual matching publication, then driver
and view repeat lifetime/selection checks. A late actor hop retains original memory
and requires reload; legacy unsealed result-only methods remain local-only.

## Existing workspace actions and retirement

**PGU-04.** Status, cancellation/reconciliation, pending restoration and archive
use the original workspace factory even if another controller is selected. Pin
full association/workspace/pending snapshots, reserve coordinator mutation while
the action runs and consume only the exact resulting sealed snapshots. Status
makes no mutation. Explicit cancel publishes intent before the idempotent request;
existing-only cancellation lookup sends no cancellation and may clear intent only
on exact cancelled root. Missing/running/unknown retains intent. Restore publishes
unchanged latest original only; archive removes metadata only after no same-scope
pending or cancellation intent and checked non-running status. Missing/unknown
requires separate accepted uncertainty. Failure/late completion retains metadata
in memory and requires explicit reload; no callback or fixture supplies a seal.

Generated-draft assessment additionally requires current selection matches original
workspace. Use its fixed existing-only purpose to read actual draft/import and
root source/fixture handles, deduplicated by digest with matching first revision.
After sealed delivery, convert only that metadata to a new ordinary paired authoring
decision. Human confirmation obtains fresh selected custody using the authoring
contract, not the expired workspace session. Its actual manual candidate receipt
can enter attribution/review; generation status never substitutes for that receipt.

Opening/editing/selection/wake starts no RPC/model. Authority/grant/custody/transport,
malformed response, cancellation, late delivery or selection generation failure
retires context, workspace display, feedback, inputs and confirmation while keeping
durable originals. Ordinary invalid input preserves only still-current context.
No timer, automatic refresh, stopped-model assertion or physical dispatch is added.
