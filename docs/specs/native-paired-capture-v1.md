## Candidate and publication

Only an actual selected production session may transfer custody into a new
original purpose. Derive deployment/owner/epoch/principal from its authenticated
scope and paired association/controller/creation/verifier from its retained
association. Canonicalize the caller's exact closed input with pending phase.
Native target-access inputs refuse. Preserve current scope correspondence and
ordinary input, author, epoch and generation rules. There must be no existing
original in the same deployment/owner/epoch, even in another category. Preserve
all other originals, old-root compatibility, the shared sixteen-original bound
and the exact full pending snapshot.

A public candidate is metadata only; pure comparisons or decoded scope never
construct a successful session. Capturing a candidate requires the actual
selected purpose and exact equality with its own derived candidate. It accepts
no raw bearer, injected successful backend, alternate directory or decoded
scope as a session. Remember that exact candidate in the one coordinator before
the possible private publication. It contains no bearer.

Use the original selected signed access, existing credential, association
snapshot and five-second continuous deadline throughout publication and all
later requests. Before retaining the candidate, check actual original app and
association plus the full pending snapshot. Publish its exact bytes through the
fixed private journal CAS. Afterward verify actual resulting pending/association
custody and the same original app, without new credential/scope acquisition or
renewal. A closed original-purpose consumer for that exact pending entry is
returned only after confirmed publication and bounded delivery. Its first
explicit submission uses the existing original retry meaning and fixed runner;
no request is sent by capture itself.

Blocked/cancelled/expired or unconfirmed publication sets reload-required and
preserves remembered metadata. Late disk completion cannot deliver a consumer
or clear memory. No input, phase, ID, principal or owner is silently replaced.
Loading, menu opening and selection still perform no Keychain, lookup or request.
