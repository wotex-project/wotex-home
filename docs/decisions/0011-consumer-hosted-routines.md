# ADR 0011 — Consumer-hosted reusable routines

Status: accepted target decision, 2026-10-13. Generic extraction is planned.

Use WoTEx TD/TM and compatible Continuum values for descriptions and exchanges.
Build one optional routine kernel with explicit consumer inputs and bounded
decisions. The consumer owns its authority, persistence, trusted clocks,
credentials, supervision and physical-effect outcomes. Home retains one
Authority and Store; the native shell remains a client.

Use ExBooking directly for generic recurrence and actual availability/resource
questions. Extend its own public contract with original-occurrence enumeration;
do not convert clipped availability windows into trigger identities or add
consumer concepts to the booking kernel. Use ExMaude for declared, attributable
analysis; a negative search and positive admission remain separate.

Extract the existing source/IR semantics through public interfaces, preserving
the restricted admission subset and current full qualification identities.
Unknown facts, complete-set arbitration, uncertain handoff and nonrefundable
roots remain mandatory. Device/external timers have explicit ownership.
Independent non-household archive use is required before universal reuse is claimed.

This build track includes no Refpath dependency, execution engine or booking
wrapper. Earlier research reuse candidates remain historical alternatives,
not this plan's dependencies. Optional voice/Matter/media cannot become ordinary
routine prerequisites. No new runtime dependency is selected by this decision.

See [WOH.20](../specs/WOH.20-universal-routines.md) and the
[delivery sequence](../plans/universal-routines-delivery.md). The existing
data-first decision and physical/default-disabled gates remain in force.
