## Implemented boundary

Explicit paired configuration reads stable identity/contract/options through
current profile:manage and the actual selected factory. Context, complete
root/attempt decisions and repair feedback carry metadata and frozen inputs,
with no bearer, local capture or reusable session. Attempt preparation checks
actual root/latest status, owned invalid draft, explicit feedback and the
original root's policy/provider/basis and remaining attempt budget.

Human confirmation acquires fresh actual selected custody, checks exact reviewed
revision, unchanged grants, complete options and contract basis, then publishes
v2 workspace root/append before v8 pending. The bounded file owner and original
consumer share that same actual seal/five-second lease. Failures remember possible
workspace/pending completion and require reload. No file-only send, later session
reacquisition, edited input, automatic attempt or model-budget renewal is added.

Workspace status/cancel/restore/archive and generated-draft preparation now reserve
both coordinators and consume only the actual existing-purpose sealed snapshots.
Existing-only cancellation lookup may clear intent on matching cancelled status
without sending cancellation. Same-scope pending checks include remembered originals
and remain tied to the original workspace, irrespective of UI selection. Generated
assessment requires matching selected original and becomes an ordinary paired
manual decision for fresh confirmation; a generation receipt is not a manual one.

Typed delivery carriers preserve the actual publication through the view actor hop.
Late/cancelled delivery remembers original metadata and requires reload. The old
unsealed result-only driver methods remain local-only, and the local delivery
initializer refuses paired entries. Private input/context/status retires on scope,
custody, transport or selection failure. Physical dispatch stays disabled.
