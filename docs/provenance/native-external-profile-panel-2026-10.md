## Implemented boundary

The Things task now composes explicit catalogue/history reads and private-file
inspection, trust and read-only target decisions. The selected local driver binds
an immutable original to actual credential/reference, identity, revision, policy/
trust and selection generation. Preparation sends no mutation or pending write.
Confirmation repeats the current basis, publishes complete v9 input and invokes
the fixed status-first SDK. All refusals retain any already published original.
Files changed after review do not replace the reviewed immutable bytes.

Prepared values have private construction and redacted reflection. Their one-way
retirement reference is checked across asynchronous hops and composes with the
existing local selection/native peer boundary before each request frame and after
its reply. Parent cancellation retires the reference even when a detached worker
is waiting. Neither that reference nor the additional refusal check creates an
authorization seal, credential, endpoint or successful signing backend.

The app includes the model in busy/session guards, presentation notifications,
session/access changes and sleep/wake invalidation. Input changes clear confirmation
and retire prepared state. Historical lookup, current catalogue, approval, target
selection, grants and reports stay distinct. Paired selection refuses before file,
credential, certificate-clock or transport work; original Activity recovery retains
its separate recorded context.
