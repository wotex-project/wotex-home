## Implemented boundary

Things defaults to Guided and retains Complete decision file as an explicit
alternate. Five typed drafts accept explicit operation IDs and only the selected
action's fields. Imported envelope/profile/ordered definition references use the
owning checked codec; historical inspection fields and target/artifact IDs stay
separate. New operation, definition add/remove and source/inspection choices are
explicit actions. Persistent labels identify filled fields. Editing and opening
perform no credential capture, read or pending publication.

The selected local driver captures current custody and validates the native
principal/controller reference before domain reads. One bounded comparison group
reads current context/catalogue, action-specific inspection/artifact/target/source,
context again, the new original's exact status and final identity. Pure builders
join one current basis; metadata-only withdrawals do not require reader/source
or byte-custody availability. Source choices have their own explicit bracketed read.

Prepare allocates no pending entry. Separate confirmation freezes the exact
original. Submit reacquires custody and repeats the entire comparison group;
changed original, identity or revision refuses before journal publication. The
existing private v9 journal and status-first SDK then own publication, delivery,
receipt verification and whole-file resolution. Lifetime/selection checks still
surround async and local request boundaries. Activity recovers the exact complete
original after uncertainty. Paired selection refuses without local fallback.
